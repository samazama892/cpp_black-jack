# Design Goals

## Version 1

* [ ] Player can play as a contestant.
* [ ] Standard Blackjack rules.
* [ ] Single human player versus dealer.
* [ ] Terminal-based interface.

## Version 2

* [ ] Player can choose to play as dealer.
* [ ] Dealer AI controls contestants when needed.

## Version 3

* [ ] AI contestants can join the table.
* [ ] AI uses probability-based decision making.

## Version 4

* [ ] Multiple human contestants can play on the same computer.
* [ ] Turn-by-turn player rotation.

## Future Ideas

* [ ] Betting system.
* [ ] Statistics tracking.
* [ ] Save/load games.
* [ ] Different AI difficulties.
* [ ] Multiple decks.
